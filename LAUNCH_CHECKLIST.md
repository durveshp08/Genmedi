# Genmedi Pre-Launch Checklist

## Legal & Compliance
- [ ] Register company with Ministry of Corporate Affairs (MCA)
- [ ] Obtain GST registration for e-pharmacy operations
- [ ] Register with State Pharmacy Council
- [ ] Obtain CDSCO Schedule X license for online pharmacy
- [ ] Complete DISHA compliance documentation
- [ ] Draft and review Terms of Service
- [ ] Draft and review Privacy Policy
- [ ] Draft and review Refund Policy
- [ ] Obtain ABHA integration approval
- [ ] Complete drug licensing agreements with suppliers

## Technical Readiness
- [ ] Complete security audit (OWASP Top 10)
- [ ] Complete penetration testing
- [ ] Set up SSL/TLS certificates for production
- [ ] Configure production database with backups
- [ ] Set up monitoring and alerting (Sentry, DataDog, etc.)
- [ ] Configure CDN for static assets
- [ ] Set up log aggregation (ELK stack, CloudWatch, etc.)
- [ ] Complete load testing (1000+ concurrent users)
- [ ] Set up error tracking
- [ ] Configure rate limiting
- [ ] Set up DDoS protection
- [ ] Complete API documentation (Swagger/OpenAPI)

## Operational Readiness
- [ ] Onboard pharmacists (minimum 5 for beta)
- [ ] Onboard delivery riders (minimum 10 for beta)
- [ ] Partner with CDSCO-approved stockist hubs (minimum 3)
- [ ] Set up cold chain monitoring equipment
- [ ] Configure Razorpay production account
- [ ] Set up FCM for push notifications
- [ ] Configure SMS gateway for OTP/fallback
- [ ] Set up customer support channels (phone, email, chat)
- [ ] Create escalation procedures
- [ ] Train support team on common issues

## Post-Launch Monitoring
- [ ] Monitor order completion rate (target: >95%)
- [ ] Monitor delivery SLA compliance (target: >90% within 45 min)
- [ ] Monitor cold chain compliance (target: 100%)
- [ ] Monitor pharmacist verification rate (target: >98%)
- [ ] Monitor customer satisfaction (target: >4.5/5)
- [ ] Monitor system uptime (target: >99.5%)
- [ ] Monitor payment success rate (target: >95%)
- [ ] Monitor user retention (target: >60% after 30 days)

- **Daily Orders**: Target 50+ orders/day by end of beta

- **Cold Chain Compliance**: 100% adherence
- **Pharmacist Verification**: 98%+ verification rate
- **System Uptime**: 99.5%+ availability
